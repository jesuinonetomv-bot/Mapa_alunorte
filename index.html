Administração

Configurar o primeiro administrador
  1. No Firebase do projeto mapa-alunorte, ative Authentication → método E-mail/senha e crie sua conta.
  2. Copie o UID da conta e, no Realtime Database, adicione administradores/SEU_UID com valor booleano true.
  3. Antes de usar o editor, aplique as regras abaixo na aba Regras do banco. Elas mantêm a colaboração de percursos, pontos e bloqueios e reservam as revisões ao administrador. Se já houver outras regras ou caminhos, faça a integração antes de publicar.
{
 "rules": {
  "administradores": { "$uid": { ".read": "auth != null && auth.uid === $uid", ".write": false } },
  "mapa": {
   ".read": true,
   "ruas": { ".write": "auth != null" },
   "pontos": { ".write": "auth != null" },
   "bloqueios": { ".write": "auth != null" },
   "refinamentos": { ".write": "auth != null && root.child('administradores').child(auth.uid).val() === true" }
  }
 }
}

Não mantenha uma permissão de escrita pública na raiz ou em mapa: ela anula a proteção das revisões. O botão de administrador sozinho não protege o banco.

Desenhar ruas

Desenhe sobre os percursos gravados. Linhas: 2 cliques. Polilinha: vários cliques e Concluir. Curva: início, ponto de controle e fim. Os marcadores podem ser arrastados depois.

As rotas usam exclusivamente as ruas desenhadas e salvas. Os trajetos gravados servem apenas como referência.

Escolha uma ferramenta para começar.

Selecione uma rua no mapa. Arraste os pontos para corrigir o traçado. Os extremos encaixam em outras ruas a até 8 m. As mudanças ficam em rascunho até salvar.
